# RoleDroid
discord.js制のロールパネル作成Bot

# 誰が作ったの？
SharkBot-Devのユーザーが作成しました。

# Botの使い方
- `/create` ロールパネルを作成します
- `/add` ロールパネルにロールを追加します。
- `/remove` ロールパネルからロールを削除します。
- `/select` ロールパネルを編集する際にロールパネルを選択します。
- `ロールパネルを選択` ロールパネルをContextメニューから選択します。
